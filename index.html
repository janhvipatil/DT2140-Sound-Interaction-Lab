    • Shake up a storm

    Shake the phone to set off a thunderclap. Like a real storm, the thunder cracks and then rolls on for a few seconds; shaking again while it is still rumbling does nothing, so each clap can finish. Wait for the storm to settle, then shake again for the next strike. The thunder is a Faust model (faust-dsp/Nature/thunder.dsp) compiled to WebAssembly.
